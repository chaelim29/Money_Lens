# 💰 Money Lens 
### 데이터를 통해 나에게 맞는 금융 정보를 찾다

**Money Lens**는 금융상품과 청년정책 정보를 한곳에서 확인하고, 개인의 금융 상황과 목적에 맞는 정보를 탐색할 수 있도록 돕는 금융 정보 서비스입니다.

복잡하고 흩어져 있는 금융 정보를 쉽게 비교하고 이해할 수 있도록 데이터 수집부터 분석, 서비스 구현까지 진행하는 개인 프로젝트입니다.

---

## 1. 프로젝트 소개

- **프로젝트명:** Money Lens (머니렌즈)
- **개발 목적:** 금융 정보 접근성 향상 및 개인 맞춤형 금융 정보 제공
- **개발 형태:** 개인 프로젝트
- **개발 기간:** 2026.11 ~ 진행 중

## 2. 주요 기능

### ① 금융상품 정보 조회 및 비교
- 금융감독원 금융상품통합비교공시 API를 활용한 금융상품 데이터 수집
- 정기예금 상품 정보 조회
- 금융회사별 상품 및 금리 정보 확인
- 상품별 조건 비교 기능

### ② 청년정책 정보 제공
- 청년 대상 정책 및 지원사업 정보 수집
- 정책별 지원 대상, 신청 조건 및 지원 내용 정리
- 사용자에게 필요한 청년정책 정보 제공

### ③ AI 기반 금융상품 추천
- 사용자의 금융 목적과 조건을 바탕으로 적합한 상품 탐색
- 금융상품의 주요 조건을 분석해 개인별 추천 제공
- 금융 정보에 대한 이해를 돕는 AI 기능 구현 예정

## 3. 기술 스택

| 구분 | 기술 |
|---|---|
| Language | Python |
| Data Analysis | Pandas |
| Web Framework | Streamlit |
| API | 금융상품통합비교공시 API |
| AI | OpenAI API |
| Version Control | Git / GitHub |

## 4. 프로젝트 구조

```text
Money_Lens/
│
├── app.py              # 메인 웹 애플리케이션

├── pages/              # 서비스별 페이지
```

## 5. 개발 과정

1. 금융상품 데이터 제공 API 조사 및 인증키 발급
2. Python을 활용한 금융상품 데이터 수집
3. Pandas를 활용한 데이터 정리 및 전처리
4. Streamlit 기반 웹 서비스 구현
5. 금융상품 비교 및 청년정책 정보 제공 기능 확장
6. AI 기반 개인 맞춤형 금융 정보 서비스 개발
